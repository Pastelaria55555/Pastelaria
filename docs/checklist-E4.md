# Checklist E4 — Modelo de caixa e layout

## Requisitos do enunciado

- [x] Modelo de caixa usado de forma consistente: `box-sizing`, `margin`, `padding`, `border` e `width` estão documentados e aplicados em `css/style.css`.
- [x] Tabelas e formulário têm espaçamentos, bordas, cores e larguras coerentes com o guia de estilo.
- [x] Foram usados elementos HTML5 adicionais com propósito: `mark`, `details`, `summary`, `figure`, `figcaption` e `time`.
- [x] Artigo criado em [artigo.md](./artigo-E4/artigo.md), com tema, questão orientadora, índice e oito referências com URL e data de acesso.
- [x] O foco de teclado é visível através de `:focus` e a ordem natural de tabulação é mantida.

## Evidências e verificação

- [x] Verificação local das cinco páginas: um H1 e um título por página.
- [x] Verificação local das ligações e referências a ficheiros.
- [x] Teste manual de teclado documentado em [teste-teclado-E4.md](./teste-teclado-E4.md), com captura em `docs/evidencias/e4-teclado-menu.png`.
- [x] Validação W3C das cinco páginas depois destas alterações; capturas `w3c-E4-*.png` guardadas em `docs/evidencias/`.

## Limites desta entrega

Esta E4 usa apenas HTML e CSS já trabalhados nas aulas. Não foram adicionados JavaScript, frameworks, bibliotecas ou código de servidor.
