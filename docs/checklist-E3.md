# Checklist E3 — CSS base e validação


- [x] **Folha de estilos externa:** as cinco páginas ligam a `css/style.css`; não há CSS em linha injustificado. Registo em [relatório de validação](./relatorio-validacao-E3.md).
- [x] **Guia de estilo:** cores e tipografia definidos em [guia-estilo.md](./guia-estilo.md), com os pares de contraste documentados.
- [x] **Regras CSS:** folha de estilos organizada por secções comentadas e com mais de 15 regras.
- [x] **Contraste:** os pares de texto e fundo registados na guia cumprem os rácios mínimos de 4,5:1 para texto normal e 3:1 para texto grande.
- [x] **Validação:** as cinco páginas HTML e a folha CSS foram verificadas; os validadores indicaram 0 erros. O validador CSS apresentou ainda 3 avisos informativos sobre variáveis CSS.
- [x] **Wireframes:** páginas iniciais em [Início](./wireframes/index.md), [Menu](./wireframes/menu.md) e [Sobre nós](./wireframes/sobre.md); páginas acrescentadas em [Contactos](./wireframes/contactos.md) e [Acessibilidade](./wireframes/acessibilidade.md).
- [x] **Evidências:** capturas dos resultados HTML e CSS guardadas em `docs/evidencias/` e identificadas no [relatório de validação](./relatorio-validacao-E3.md).
